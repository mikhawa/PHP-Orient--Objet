## Conseils de travail

- Créez un dossier par chapitre (`ex00/`, `ex01/`…) et un fichier par exercice.
- Testez votre code après **chaque** étape, pas à la fin : `php mon-fichier.php` dans le terminal.
- Les sorties d'exemple sont des suggestions : votre créativité est bienvenue, surtout pour les messages rigolos.
- Bloqué·e plus de 15 minutes ? Relisez le chapitre du cours correspondant, l'indice y est toujours.
